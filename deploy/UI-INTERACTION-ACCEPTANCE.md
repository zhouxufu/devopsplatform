# 八项 UI 与交互改动验收

## 基础构建全流程补验（2026-10-12）

- 后续交互修订：未配置当前环境的提醒采用可关闭 toast，目标加载完成后才提示，同一上下文页签切换不重复；空环境只保留一个配置入口。高级流水线说明变为一次性 toast 与问号帮助，不再占用常驻提示栏。
- 新增 `shell-script` 构建节点，可排序、连续新增和编辑 Bash 内容；草稿离开确认、保存 loading，保存不执行。后台校验空内容/64 KiB/NUL；`TestShellScriptBuildStep` 验证工作区、变量、失败停止和容器参数，不访问用户源码或业务资源。

- 首页默认表格，可切卡片；按应用聚合最新构建与制品，避免全局最近记录截断导致小应用状态缺失。搜索、状态、页码在当前浏览器会话保留。
- 应用概览、构建、制品、环境、发布单统一紧凑页头。构建保留一个主入口；“构建并发布”在更多操作中显式选择目标，保护环境仍须审核。日常发布必须选择具体制品，不静默选择最新版本。
- 应用设置为工作区内分组页面；环境配置也按资源、启动检查、变量、策略分组，保存/取消返回原工作位置。组间切换保留草稿；草稿不持久化至浏览器存储，刷新前应保存。
- 构建、制品、发布记录采用服务端分页和筛选。构建可查看阶段、耗时、人员；制品展示来源构建、分支和曾成功发布环境，不把成功发布记录当作实时运行状态。环境实例管理继续通过检测获得运行状态。
- 构建详情支持阶段日志、搜索、暂停/继续跟随和复制；返回保留原筛选与页码。临时 Maven/Gradle 参数只影响本次运行。新应用保留三步接入，完成后进入构建页。
- 新构建保存加密配置快照及真实完整 Git Commit。发起人/管理员可按原源码和配置重试；当前凭据、变量、步骤实现与依赖重新授权/解析，不能保证字节级相同制品。旧记录、无法解析 Commit、本地工作目录及有前置命令的构建不提供精确重试；不会自动再发布。
- 取消须填写原因且记录审计，只终止当前执行器拥有的构建进程组/容器，不操作部署实例；执行器退出后才释放运行锁。Windows 没有进程组实现，只提供直接进程取消，不能承诺清理全部子进程。
- 验证：`go test ./...`；构建/权限/快照/取消/固定 Commit 测试和 `-race` 针对性测试；`test-basic-build-workbench-ui.mjs` 覆盖分页返回、日志过滤、参数隔离、分组草稿、准确制品、环境编辑、明暗主题及 1440/900/700/390 布局。所有业务写请求均模拟，不触发用户构建、部署或业务库操作。

## 工作台研发操作补验（2026-10-10）

- 查询与变更提交保持同级，侧栏只保留公共中心入口；审批设置放进“设置”。实际目标只展示连接名、库/DB 和 Key 前缀，不返回凭据，也不在打开页面时查询业务数据。
- 查询页签分别保留环境、内容和结果，最多 10 个；Ctrl/⌘ + Enter 执行选中内容或全文。SQL 高亮、格式化、查表、结构查看及结构字段插入可用。近期查询与对照结果仅在当前页面保留，不承诺刷新恢复。
- 交互查询支持单表 `SELECT *`、别名、WHERE、排序、分组、COUNT/MIN/MAX/SUM/AVG、LIMIT，以及 `SHOW TABLES`、`DESCRIBE 表名`。默认 200、最多 1000 行，30 秒超时，结果最多 2 MiB；不支持 JOIN、子查询、任意函数、序列、锁与多语句。数据同步仍使用独立的严格语法。
- Redis 使用带准确资源前缀、游标与 COUNT 1–100 的 SCAN；结果可点选查看类型/TTL、载入下一游标、生成准确 Key 的清理或过期草稿。Hash/List/Set/Sorted Set 支持有限范围读取，禁用 KEYS、全量集合返回；在 RESP 响应头阶段限制大小，GET 最多显示 64 KiB。所有辅助操作只载入命令或草稿，不自动执行。
- 查询结果支持复制、详情、JSON 格式显示及基于非空唯一键的两次结果数量对照；仅对比已经返回的范围，不等同于完整数据同步，不自动生成写操作。
- “以此新建变更”保留核对查询，不把 SELECT/只读命令复制到写编辑器。预检保存草稿但不标记就绪；编辑会使旧预检失效。实际提交才标记就绪，审核与执行仍分开。当前会话中提交的执行单可返回原核对查询，不自动重查。
- 记录可按我的操作、待我审核和关键词筛选；Redis 执行单显示逐条命令台账（成功/尚未开始/结果不确定），失败不自动重试。仅展示服务端最近返回的记录，不声称完整历史分页。
- 后端用例：`TestWorkbenchSQLIndependentGrammar`、`TestWorkbenchRedisReadBoundsAndScope`、`TestWorkbenchBoundedRedisScanProtocol`、`TestWorkbenchDraftPreviewNeverCreatesExecutionPermit`、`TestWorkbenchTargetAndLedgerScope`。浏览器用例 `test-workbench-ui.mjs` 覆盖页签和结果保留、选中执行、格式化字面量、结构查看、Key 点选/游标、核对查询、预检可编辑及失效、审批、无自动执行、公共中心连续性和响应式布局。
- 后端仅使用临时数据库与回环 Redis 协议测试服务；浏览器业务请求全部模拟。真实 MySQL SQL 执行集成需要可丢弃的本地测试库，本次不访问用户业务数据。

日期：2026-10-10。分支：`feature/delivery-platform-v1`。验收对象：本地 `http://127.0.0.1:9800/`，壳内工作区和独立插件页面。

## 页头一致性补验（2026-10-10）

此前视觉用例主要覆盖边距、侧栏、主题与溢出，不能证明各页面标题和页签同排；这一缺口已由公共组件与专用布局断言补齐。

- 构建、编排、变更、应用详情和插件中心使用同一组件；应用代码来源说明转入问号，长名称截断后仍有完整名称提示，环境状态和构建/部署动作保留。
- 数据库 SQL 查询和提交 SQL、Redis 查询和提交命令变更仍是同级入口；没有改变审批策略、执行行为和草稿保活方式。
- 日志订阅、监控报警、规则、机器、JVM 和接口页复用公共页头；接口页筛选条件较多时允许自然换行，不把筛选误作页签。
- 日志搜索/实时日志、Trace 查询和监控总览原本直接展示操作工具栏或数据，不为形式一致额外增加标题占用。资源中心仍保留自身分类导航，避免挤入页头产生拥堵。
- 应用详情验收使用只读模拟应用和环境，覆盖长名称和运行环境徽标，不依赖本地恰好存在应用，也不会创建真实应用或执行部署。

## 明暗主题实时同步补验（2026-10-10）

- 原因：壳已发送 `theme.sync`，但 Vue 插件的公共主题模块只读取启动偏好，没有监听后续消息；MCP 初始偏好也与壳不一致。
- 公共主题模块实时应用来自同源父窗口的布尔主题消息，统一原生控件的 `color-scheme`；独立页面通过 `storage` 事件同步偏好。壳的切换图标和标签使用响应式主题状态，MCP 采用相同规则。
- `test-theme-sync.mjs` 验证可信消息、错误来源/类型拒绝、重复初始化不重复监听、跨窗口同步以及存储不可用时的降级。
- `test-theme-sync-ui.mjs` 实际点击壳的主题按钮，覆盖部署、数据库、Redis、日志、监控、MCP 的当前和后台工作区、新开/重新加载文档、独立页面及第二个壳窗口；检查原生控件和 Element Plus 色板同步、页面不重新加载或导航。禁止业务写请求，不修改用户数据库和审批配置。
- 复测：`node scripts/test-theme-sync.mjs`、`node scripts/test-theme-sync-ui.mjs`。浏览器测试使用独立上下文，不改变用户浏览器中的主题偏好。

## Agent 与资源检测等待反馈补验（2026-10-12）

- Agent 检测、SSH 测试、采集配置读取、列表安装/升级以及资源连接测试显示真实请求期间的转圈、阶段文字和完成/失败提示。同一主机的相关操作互斥，不影响其他主机检测；连接测试也拦截重复点击。
- 采集配置立即打开读取中窗口；关闭读取窗口或切换主机后，旧响应不覆盖当前配置。保存、安装、下发分阶段提示，整条链路结束才解除 loading。提交期间禁止编辑或关闭该配置窗口，避免改写提交目标；读取期间仍可关闭。
- 配置窗口操作区固定在可见底部；失败恢复按钮并保留采集内容。下发成功后的原始配置重新转成编辑器结构，避免日志路径编辑值丢失，支持后续继续修改。
- `test-agent-loading-ui.mjs` 拦截所有业务请求，使用可控延迟与失败响应覆盖加载状态、禁止重复、主机隔离、读请求过期、保存/安装/下发阶段、失败重试、输入与窗口保护、路径保留和四种宽度；没有真实 SSH、安装或配置下发。配合采集合并规则单测、工作台与公共中心回归，保持其他弹窗默认关闭/取消行为。

## 部署编排连续交付补验（2026-10-12）

- 选择范围、制品与步骤、预检提交改为全页三段流程；编排编辑保存后回到原步骤。执行详情也是页面，日志使用可关闭的侧边区域，审核快照与节点参数按需展开。返回列表保留筛选；未提交草稿在当前页面实例内保留，刷新前仍须完成提交，不承诺持久恢复草稿。
- 执行单服务端分页，支持环境、版本、发起人、状态、日期与关键字。候选制品独立分页，可按版本或来源分支检索；不默认选择最新制品。
- 版本制品映射人工确认代码覆盖，首次提交后锁定。展示来源构建编号和分支，但没有自动分支合并、自动验证 BUG 代码覆盖。固定服务模式仍可独立使用。
- 预检凭证绑定输入、制品、目标与私密配置，10 分钟有效；修改或目标漂移须重新预检，同一凭证重复提交返回同一执行单。预检和提交期间的相关输入/按钮锁定并显示 loading。
- 显式启动后台顺序协调器，审批本身不启动。普通节点自动推进；人工、批次观察、失败及中断均停止或等待，操作人核对后明确继续。暂停只停止后续步骤，不强制杀掉已启动操作。协调器有持久租约，不在程序重启后自动重放 SQL / Redis / Nacos 写操作。
- 故障页显示节点结果；接续编排只复制未完成应用与尚未启动的其他节点，排除成功节点及失败/中断的写操作。应用回退先核对各实例旧制品是否一致，生成新的交付草稿重新预检与审核，不调用直接回滚接口绕过生产审核。Nacos 恢复仍创建独立审核草稿；不承诺跨服务原子恢复。
- 不确定写操作可在暂停/中断后明确终止后续编排，必须填写原因并保留原执行状态；终止不是撤销操作，也不将台账伪装为“未执行”。活跃子发布必须先处理，批次观察处支持取消尚未发布批次，不回退已完成主机。

## 导航模式与日期筛选补验（2026-10-12）

### 紧凑日期浮层统一调整

- 日期筛选仅保留一个范围入口，不再有“单侧”模式按钮。统一浮层内使用两个中文 Element Plus 日期选择器，开始/结束均可清空；今天、最近 7 天、最近 30 天保留为快捷项。草稿需“应用时间筛选”后才改变实际条件，取消不改变条件，倒序范围阻止应用。
- 版本候选的“更新时间”也直接使用范围框，与编号清单分离；编号批量筛选使用独立小浮层。保留完整跨页选择，不因弹出日历、退出日历或编号浮层丢弃版本输入。
- 全部日期面板悬浮，不参加父筛选栏的高度布局。日志/监控原有范围组件与同步/连接基线继续使用原生 Element Plus 浮层；统一限制窄屏弹层尺寸，内部滚动而不撑宽页面。Escape 优先关闭日历，不直接关闭承载它的工作项选择弹窗。
- 补验比较打开统一浮层/日历、应用/取消/清空前后的筛选栏高度及表格起点；覆盖开始单边、结束单边、四种宽度下的已打开日历、编号浮层、中文显示、精确到秒的本地边界、独立日期基线与其他筛选条件保留。所有同步/版本保存业务写入均拦截模拟。

### 导航及日期基础验收

- 部署、DBMS、Redis、日志、监控使用同一个导航组件。默认 64px 图标栏，鼠标移入展开 176px 抽屉，正文不移动；点击固定后正文让出 176px。模式保存在本浏览器，同源工作区同步，不改变路由、不重建编辑器或 iframe。
- 键盘及触屏可以用顶部导航按钮展开；抽屉支持 Escape、点击外部和离开收起。760px 及以下临时使用抽屉，恢复桌面宽度后继续沿用固定偏好。固定按钮有可读名称和按下状态，动画尊重系统减少动态效果设置。
- 所有日期筛选使用 Element Plus 中文日期组件：日志/监控时间范围保留原来的动态范围，工作项候选日期保留包含当天的边界，编排记录使用带秒的本地日期时间，同步和连接基线仍提交 YYYY-MM-DD 字符串。清空依然表示不限日期或沿用连接设置，不擅自设置今天。
- `test-sidebar-date-ui.mjs` 验证五个插件、跨工作区偏好、鼠标/键盘/窄屏、查询组件未重建、输入保留、中文日期与时间面板、本地秒数以及清空语义。同步请求被拦截，仅核对参数，未同步来源或写入业务数据库。
